The idea

A personal project in real-time application engineering.

A personal multiplayer application developed with Python and JavaScript. The project covers real-time communication, application state, persistence, authentication and deployment, with a browser-based game as the user-facing experience.

The approach

01

Connect players

Support 2-8 players using WebSocket communication.

02

Handle state and access

Use SQLite persistence, PBKDF2 password hashing, token-based authentication and rate limiting.

03

Test and deploy

Integrate automated tests and deploy the web experience on Cloudflare Workers.

From implementation
to understanding.

Beyond the game itself, this project is practical experience in building an application across its interface, backend, data layer and release process.
