The idea

Machine learning for structural damage classification.

An academic classification project using building characteristics to estimate post-earthquake damage levels. The work compares Random Forest and LightGBM, with a final ensemble and a structured tuning and evaluation process.

The approach

01

Prepare

Organise the building-level input features and target damage classes.

02

Compare

Tune Random Forest with randomised search and LightGBM with Optuna.

03

Evaluate

Use nested cross-validation to separate hyperparameter selection from outer-fold evaluation.

What I took from it

From implementation
to understanding.

Model comparison is useful only when the evaluation protocol is clear. This project developed my experience with classification pipelines, hyperparameter optimisation and ensemble methods.
