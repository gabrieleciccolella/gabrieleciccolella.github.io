Cancer Cell Classification

Manual K-NN implementation for benign vs malignant cell identification.

Home Projects Contact

Project Overview

This project focuses on designing and implementing a supervised learning pipeline to classify cancer cell samples into benign and malignant categories. The central goal was to develop an end-to-end system capable of reliable medical prediction while maintaining interpretability.

The entire algorithm was based on the K-Nearest Neighbors (K-NN) method — a simple yet powerful distance-based classifier. The key characteristic of this work is that the K-NN algorithm was implemented manually, without relying on external libraries such as scikit-learn.

This manual approach allowed a deeper understanding of the mathematical foundations of distance metrics, normalization, and decision logic — essential aspects of machine learning transparency and reproducibility.

Methodology

  • Algorithm: Custom implementation of K-Nearest Neighbors (K-NN) from scratch in Python.
  • Distance Metrics: Euclidean and Manhattan distances tested for robustness.
  • Normalization: Min-Max scaling applied to avoid bias from large numerical ranges.
  • Cross-Validation: Custom validation routines using multiple splitting strategies (Holdout, Random Subsampling, Stratified Shuffle Split).
  • Decision Logic: Majority vote across nearest neighbors, dynamically adjusting k to optimize accuracy.

This structured implementation ensured full control over data flow, metric calculations, and classification performance.

Validation Strategies

  • Holdout: Fixed percentage split (e.g., 80% training / 20% test).
  • Random Subsampling: Multiple random dataset splits to assess model consistency.
  • Stratified Validation: Maintains benign/malignant balance in every iteration — ideal for imbalanced data.

Each method tests the generalization of the manually implemented K-NN model.

Evaluation Metrics

Several metrics were calculated after each validation to provide a detailed understanding of the classifier’s performance:

  • Accuracy: Overall proportion of correctly classified samples.
  • Error Rate: Fraction of incorrect classifications.
  • Sensitivity (Recall): Ability to correctly detect malignant cells.
  • Specificity: Ability to correctly detect benign cells.
  • Geometric Mean: Balances Sensitivity and Specificity for reliable global evaluation.

These metrics offered a holistic and interpretable view of how the manually coded K-NN behaved under multiple validation conditions.

Results Summary

The manually implemented K-NN achieved results comparable to standard library implementations, confirming the correctness and stability of the custom code. The classifier demonstrated solid accuracy and balanced sensitivity/specificity trade-offs, proving the reliability of a from-scratch ML pipeline.

Beyond its performance, the project emphasized algorithmic transparency and educational insight — showcasing how classical methods can still serve as excellent teaching and diagnostic tools in AI-driven medicine.
