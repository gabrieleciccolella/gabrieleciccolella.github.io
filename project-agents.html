The idea

Connecting an AI workflow to an observable system.

An academic project combining a requirements-analysis agent with a service architecture. n8n coordinates the workflow, Ollama provides local model inference and Redis supports the integration. Six Docker Compose services form the environment.

The approach

01

Integrate

Connect the conversational workflow, model service and supporting components.

02

Containerise

Define the six-service environment with Docker Compose.

03

Observe

Add metrics, dashboards and availability alerts to make system behaviour visible.
